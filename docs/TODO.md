## Deferred — 远程唤醒、开机与机外能力

当前 Remote Panel 运行在目标工作站上，机器关机后 Panel 自身无法完成开机。

暂缓：

- Wake-on-LAN；
- 路由器 / NAS / 树莓派 / 其他常在线设备代发 WoL；
- 智能插座 + BIOS 来电自启；
- 机外 watchdog / agent。

在真实使用明确需要前，不进入 v0.2。

## Deferred — 多主机

继续保留现有架构解耦成果，但不开发实际多主机 UX：

- AuthProvider 保留；
- Workflow Registry / revision / artifact 保留；
- 不新增 Host Registry、Machine Selector、per-job host routing。

多主机留给后续 v0.3 / v0.4 再评估。
