# Comfy Remote 工作流使用说明

## 设计原则

Comfy Remote 不尝试在手机上重新实现 ComfyUI。工作流应该先在本机 ComfyUI 中调好；手机端只暴露真正属于“创作输入”的内容，例如提示词、参考素材、画幅/尺寸和生成数量。

因此默认流程是：

```text
ComfyUI 工作流
→ 导出（API）
→ Comfy Remote 自动识别基础输入
→ 确认 / 测试
→ 启用
→ 在“创作”页使用
```

节点 ID、内部连接、模型、LoRA、Sampler 等信息不会因为它们存在于 JSON 中就自动出现在手机主界面。

## 导入 API Workflow

1. 先在本机 ComfyUI 中确认工作流能够正常运行。
2. 使用 ComfyUI 的“导出（API）”保存 JSON。
3. 在 Comfy Remote 右上角进入 **设置 → 工作流 → 导入工作流**。
4. 填写前端显示名称并选择 API Workflow JSON；内部工作流 ID 会自动生成，也可在高级流程中保留原 ID。
5. Comfy Remote 检查节点和连接关系，并优先识别常见基础输入。
6. 确认主要输出后保存并启用。需要时可执行真实测试任务；测试会消耗 GPU。

## 自动识别的基础语义

v0.2 重点识别：

- `positive_prompt`：正面提示词。
- `negative_prompt`：负面提示词。
- `reference_image`：可替换的参考图片输入。
- `width` / `height`：图片尺寸，并在移动端提供常用画幅快捷调整。
- `batch_size`：生成数量。
- `image` / `video` 主输出：根据 SaveImage、SaveVideo 等输出节点识别。

对于采样工作流，正负提示词会优先通过 sampler 的 `positive` / `negative` 连接向上追踪，而不是简单依赖两个相同的 CLIPTextEncode 节点名称。

如果存在多个参考图或多个输出候选，导入界面只要求用户确认候选，不会把所有未连接字面输入默认铺开。

## 高级节点映射

自动识别不可能覆盖所有自定义节点。导入页面保留：

**高级 · 手动节点映射**

这里可以显式追加需要远程修改的字面输入。连接到其他节点的输入不会被默认暴露；模型名、LoRA、VAE、文件路径等高风险或高复杂度输入也不会自动成为手机参数。

这部分是高级回退能力，不是普通导入流程。

## 创作页如何适配工作流

创作页按照工作流声明的输入和输出组合 UI，而不是为每种模型写一套独立页面。

### FL2VA

显示提示词、可选首帧/尾帧、时长、画幅、分辨率以及工作流允许的高级参数，输出视频。

### Ref2VA

显示提示词和统一“参考素材”区域；图片、视频和音频以横向素材条管理。内置 H3 Ref2VA 支持最多 9 图、3 视频、3 音频，输出视频。

### 普通生图 / WAI 类工作流

典型界面为正面提示词、可折叠负面提示词、可选参考图、画幅/宽高、生成数量，输出一张或多张图片。没有声明的高级参数不会出现。

## 工作流状态与显示名称

设置页可对已登记工作流执行启用/禁用。内置六个 H3 工作流也允许修改 **前端显示名称**；显示名称不会改变内部 workflow ID，因此不会破坏历史任务、revision 或 retry。

Builtin 工作流不能删除。自定义工作流还可以编辑高级映射、复制、导出和删除。

## 修订与历史

再次保存相同 ID 会创建新 revision。每个任务保存提交时的：

- workflow ID；
- workflow revision；
- 完整 workflow snapshot；
- input values。

因此后续编辑、重命名、禁用甚至更新当前工作流，都不会改变已有历史任务的提交依据。

## 媒体与输出

自定义工作流可以把 LoadImage、LoadVideo、LoadAudio 节点声明为固定上传槽位。内置 Ref2VA 使用 schema v2 的声明式媒体集合支持动态图片、视频和音频。

输出通过通用 artifact API 登记，可为：

- image；
- video；
- audio；
- file。

图片任务可拥有多个输出；移动端任务页会以图片网格呈现。视频任务继续支持 Range 播放和下载，旧 H3 `/video` 地址保持兼容。

## Remote Workflow Package

“导出”生成 ZIP，包含：

- `workflow-api.json`
- `remote-config.json`
- `metadata.json`

导入时会拒绝未知文件、绝对本地路径以及 `password`、`token`、`secret`、`api_key` 等敏感字段。分享包不得包含模型、LoRA、上传素材或生成结果。

## v0.2 实机验收

发布前至少使用真实 ComfyUI 验证以下三条完整链路：

1. **FL2VA**：选择工作流 → 首尾帧/提示词 → 设置 → 生成 → 视频播放 → 再次生成。
2. **Ref2VA**：多图 + 视频 + 音频 → 提示词 → 生成 → 视频结果 → 保留素材重试。
3. **普通生图 / WAI**：正负提示词 → 可选参考图 → 画幅/宽高 → 批次数量 → 多图结果 → 下载 → 再次生成。

CI 只验证代码、API、数据库、wheel 和回归测试；真实模型、GPU、第三方节点和本机工作流仍需要实机验收。
